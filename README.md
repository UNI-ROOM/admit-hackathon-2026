# ECHO: God Mode

**ECHO: God Mode** — это игра-головоломка с временной петлей, которая полностью управляется жестами рук прямо в браузере.

## 🚀 Как запустить игру

Для комфортной игры вам понадобится **веб-камера** и **хорошее освещение**!

### 🐳 Запуск через Docker (Рекомендуемый способ — в 1 команду)

Собрать и запустить production-контейнер с Nginx:
```bash
docker compose up --build
```
Игра сразу доступна в браузере:
- **`http://localhost:5173`**


Остановить контейнер:
```bash
docker compose down
```

---

### 💻 Локальный запуск для разработки (Node.js / npm)

1. Перейдите в папку с игрой:
   ```bash
   cd echo
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Запустите сервер для разработки:
   ```bash
   npm run dev
   ```
4. Откройте в браузере: `http://localhost:5173`

## ✅ Чек-лист хакатона (Как мы выполнили критерии)

- **3 обязательных жеста**:
  - 🖐️ **Открытая ладонь** (Open Palm) — начать игру.
  - 🤏 **Щипок** (Pinch) — захват объектов.
  - ✊ **Кулак** (Fist) — удерживайте 5 секунд для полного сброса (reset).
- **Наш "Твист" (Режим обработки ошибок)**: Мы добавили систему динамических подсказок! Если при распознавании ладони какие-то пальцы согнуты, система точно подскажет, какие именно. Если вы промахнулись мимо рычага при щипке, игра подскажет: "Промахнулись мимо рычага, сдвиньте руку влево/вправо".
- **Никакой заранее заготовленной логики**: Вся игровая логика (логика canvas в `index.html`) была написана строго во время хакатона с использованием MediaPipe CDN с нуля.

## 🎮 Правила игры

- **Обучение**: В начале игры вы пройдете короткий туториал, который научит вас базовым жестам.
- **Раунд 1 (10 секунд)**: Игрок должен потянуть рычаг вниз и удерживать его.
- **Раунд 2 (Временная петля)**: Появляется Призрак (Ghost), который в точности повторяет ваши действия из первого раунда (тянет рычаг и открывает дверь). В это время Игрок должен схватить человечка и дотащить его до выхода, пока дверь открыта!
