# Правила для агентов

- Не пиши комментарии в коде: ни `//`, ни `/* */`, ни `<!-- -->`, ни JSDoc, ни `#` в Python. Код должен читаться сам по себе: помогай себе именами функций и переменных.
- Допустимы только служебные директивы, без которых код не работает: `// @ts-expect-error`, `/// <reference ... />`, `/* @vite-ignore */`, shebang.
- Если правишь файл, в котором остались старые комментарии, не добавляй новых и не восстанавливай удалённые.
