# HACKATHON_SPEC (Задание)

**НАПРАВЛЕНИЕ:** Игра (Управление персонажем/объектами жестами)
**ПЛАТФОРМА:** Браузер (Webcam, без клавиатуры и мыши)

## ОБЯЗАТЕЛЬНЫЙ МИНИМУМ
- [x] Распознавание движений через веб-камеру в реальном времени.
- [ ] Минимум 3 разных движения/жеста с разными действиями.
  *Текущий статус: Есть 2 жеста (Открытая ладонь — старт, Щипок — захват). Нужен 3-й жест (например, Кулак — сброс/пауза, или Указательный палец — активация чего-то).*
- [x] Понятная обратная связь (скелет руки, подсветка при захвате).
- [x] Законченный сценарий от начала до результата (цикл записи -> петля -> победа -> рестарт).
- [x] Работает в браузере без установок (MediaPipe Hands CDN).

## ОБЯЗАТЕЛЬНОЕ УСЛОВИЕ (ТВИСТ): РЕЖИМ «ОШИБКА»
Приложение должно не только распознавать правильные движения, но и замечать неточные, выдавая **конкретную** подсказку.
*Текущий статус: Слабый. Есть только toast "Рука опущена".*
**План реализации Твиста:**
1. **Неполная ладонь:** Если игрок пытается стартовать, но выпрямил только 2 пальца, игра скажет: *"Выпрями все пальцы (сейчас согнут безымянный), чтобы запустить таймер"*.
2. **Промах мимо рычага:** Если игрок сделал щипок, но чуть-чуть не достал до объекта, вычисляем расстояние: *"Ты сжал пальцы в 10 пикселях от рычага. Смести руку правее!"*.
3. **Уход из кадра:** *"Подними руку выше в кадр, иначе твой клон исчезнет из записи!"*.

- [ ] Звук и визуальные эффекты (нужно добавить аудио).
