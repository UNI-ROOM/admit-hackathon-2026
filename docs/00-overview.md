# ЭХО — обзор проекта и навигация по документам

> Игра для веб-камеры, в которой ты проходишь уровень в команде со своими прошлыми версиями.
> Раунд 1 — ты один. Раунд 2 — рядом полупрозрачный клон, повторяющий всё, что ты делал в раунде 1. Раунд 3 — вас трое.
> Головоломки решаются только командой: одно Эхо держит рычаг, второе закрывает лазер щитом, ты проходишь к выходу.

## Ключевые решения (TL;DR)

- **Трекинг:** MediaPipe Tasks Vision → `PoseLandmarker` (33 точки тела, модель `lite`, GPU). Не Hands, не Holistic.
- **Стек:** Vite + TypeScript + один `<canvas>`. Без React, без Phaser. Игра — 2D-«комната» из 5 дорожек (lanes).
- **Магия Эха:** запись = массив кадров `{t, landmarks}` за раунд фиксированной длины; клон = тот же массив, прогнанный через **тот же** распознаватель поз, что и живой игрок. Один код правил для всех актёров.
- **Жесты (5, нужно ≥3):** шаг влево/вправо (позиция), рука вверх (рычаг), присед (низкая кнопка / поднырнуть под луч), щит (скрещённые руки — блокирует лазер), обе руки вверх (подтверждение в меню).
- **Твист:** правила подсказок работают на тех же величинах, что и распознаватель, поэтому подсказка всегда конкретна: «Подними правую руку выше — ещё 15 см до рычага», «На плите уже стоит Эхо №1, тебе нужна другая».
- **Без мыши вообще:** меню управляется курсором-ладонью с задержкой (dwell 1.2 с). Мышь тоже работает — жюри может кликать.
- **Деплой:** GitHub Pages / Vercel (нужен HTTPS для камеры). Модель грузится с CDN jsdelivr.
