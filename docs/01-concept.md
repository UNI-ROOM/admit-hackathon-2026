# 01 — Концепт: «ЭХО»

## Одна фраза

Кооперативная головоломка, где твой напарник — ты сам минуту назад.

## Core loop (один уровень)

```
 Раунд 1 (20 с)          Раунд 2 (20 с)             Раунд 3 (20 с)
 ┌──────────────┐        ┌──────────────┐           ┌──────────────┐
 │ Ты один.     │  запись│ Эхо №1 ▒     │   запись  │ Эхо №1 ▒     │
 │ Идёшь к      │ ─────▶ │ повторяет    │ ────────▶ │ Эхо №2 ▒     │
 │ рычагу,      │        │ раунд 1.     │           │ Ты идёшь     │
 │ держишь руку │        │ Ты ставишь   │           │ к выходу     │
 └──────────────┘        │ щит на луч   │           │ → ПОБЕДА     │
                         └──────────────┘           └──────────────┘
```

1. Раунд стартует по обратному отсчёту. Таймер — **единое время раунда** (0…T секунд).
2. Всё, что делает тело игрока, записывается: 33 точки скелета × ~20 кадров/с.
3. Раунд заканчивается по таймеру или раньше — если игрок дошёл до выхода (уровень пройден).
4. Если не дошёл — «Перемотка»: экран показывает, что успел сделать клон («Рычаг удержан с 4 с до 20 с ✅»), и начинается следующий раунд, где предыдущие записи проигрываются как полупрозрачные Эхо.
5. Уровень пройден → очки за время и число использованных Эхо → следующий уровень → финальный экран с итогом и таблицей рекордов.

## Почему именно это (мапинг на критерии жюри, 100 баллов)

| Критерий | Баллы | Как закрываем |
|---|---|---|
| Работоспособность | 30 | Линейный сценарий: калибровка → обучение → 3 уровня → итоги. Всё в браузере, одна ссылка. Главный риск — распознавание тела, см. [05-roadmap.md](05-roadmap.md) «MVP-линии». |
| Режим «ошибка» | 20 | Подсказки строятся из тех же чисел, что решают «сработал жест или нет». Поэтому они конкретны по определению: «не хватает 15 см», «ладони разошлись». Плюс уникальный для нашей идеи класс подсказок — про клонов: «Эхо №1 отпустит рычаг на 12-й секунде, торопись». См. [04-error-mode.md](04-error-mode.md). |
| Техническая реализация | 20 | Своя логика: распознаватель поз на правилах с калибровкой и гистерезисом, система записи/воспроизведения, движок правил уровня (рычаги/двери/лазеры), движок подсказок. Уровни описаны данными (JSON), а не хардкодом. Чистая структура модулей. |
| UX и дизайн | 15 | Без мыши от первой до последней секунды. Обучающий уровень учит каждому жесту по одному. Клоны — читаемые цветные силуэты с номерами. Таймлайн действий клона между раундами. |
| Оригинальность | 10 | Механика «кооп с самим собой» через веб-камеру — жюри её не видело в 163 проектах почти наверняка. Это главная ставка. |
| Бонусы | 5 | Своя логика распознавания ✅, таблица рекордов (localStorage) ✅, звук + эффекты ✅, телефон — если останется время. |

## Что делает идею реализуемой за 2 дня

- Запись — это `Float32Array` на кадр. Воспроизведение — поиск кадра по времени + интерполяция. Никакого ML сверх MediaPipe.
- Клон проходит через **тот же распознаватель**, что и живой игрок. Значит правила уровня («рычаг зажат, если в зоне рычага есть актёр с поднятой рукой») не различают человека и Эхо. Одна функция `evaluate(level, actors, t)`.
- Мир — одномерный: 5 дорожек по горизонтали камеры. Позиция игрока = X центра таза. Никакой физики, коллизий, прыжков через пропасти.

## Чего НЕ делать (ловушки)

- ❌ Не делать 2D-платформер с гравитацией и прыжками. Прыжок через камеру распознаётся плохо, физика съедает день.
- ❌ Не делать Hands + Pose одновременно. Один трекер. Пальцы не нужны.
- ❌ Не делать мультиплеер по сети. Эхо — уже «мультиплеер».
- ❌ Не тратить время на бэкенд. Рекорды — `localStorage`.
- ❌ Не делать больше 3 уровней + обучение. Лучше 3 отполированных с хорошими подсказками.
- ❌ Не делать столкновения между актёрами. Эхо — призраки, сквозь них можно проходить. Единственное «занято»: две фигуры на одной плите считаются как одна (отсюда подсказка «плита уже занята»).
- ❌ Не убивать игрока за ошибку. Веб-камера шумит; смерть с рестартом раунда бесит. Ошибка = стан на 2 с + красная вспышка + подсказка.

## Тон и визуал

- Стиль: неоновая «лаборатория времени» на тёмном фоне. Видео с камеры — затемнённый фон (или маленькое окно в углу), поверх — яркий скелет игрока и цветные полупрозрачные скелеты Эхо (циан, маджента, жёлтый) с номерами над головой.
- Звук: WebAudio-синтез (без ассетов): щелчок рычага, гул лазера, «вжух» перемотки, аккорд победы.
- Название на экране: **ЭХО** / подзаголовок «сыграй в команде с самим собой».
