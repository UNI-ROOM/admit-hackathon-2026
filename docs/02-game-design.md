# 02 — Геймдизайн

## 1. Мир

Экран = комната из **5 дорожек (lanes)** слева направо. Позиция актёра — дорожка, в которую попадает X центра таза (среднее точек 23 и 24). Камера зеркалится: шаг влево в жизни = влево на экране.

```
 lane 1     lane 2     lane 3     lane 4     lane 5
┌─────────┬──────────┬──────────┬──────────┬─────────┐
│ [РЫЧАГ] │          │  ~~~~~~~ ЛАЗЕР ~~~~~~▶│ ║ДВЕРЬ║│
│         │  [ПЛИТА] │          │          │ ВЫХОД   │
└─────────┴──────────┴──────────┴──────────┴─────────┘
                      ▲ старт (центр кадра)
```

Границы дорожек — по нормализованному X: `[0, .2, .4, .6, .8, 1]`. Лучше сделать центральную дорожку чуть шире (`[0,.18,.38,.62,.82,1]`), потому что игрок стартует в центре и чаще там.

## 2. Жесты (позы)

Все проверки — на **нормализованных** координатах MediaPipe Pose, расстояния делятся на длину торса `torso = dist(midShoulder, midHip)`, чтобы не зависеть от расстояния до камеры. Формулы — в [03-architecture.md](03-architecture.md#распознаватель-поз).

| # | Жест | Как делается | Что делает в игре | Обратная связь |
|---|---|---|---|---|
| 1 | **Шаг** влево/вправо | Переступить в соседнюю дорожку | Перемещение; вход в зону объекта | Подсвечивается дорожка под ногами, объект в зоне «дышит» |
| 2 | **Рука вверх** (Л или П) | Запястье выше макушки | Держит **рычаг**, пока рука поднята. Рычаг открывает дверь | Рычаг переключается со щелчком, дверь открывается, над головой иконка ✋ |
| 3 | **Присед** | Таз опускается ≥ 0.35 торса от калиброванной стойки | (а) нажимает **низкую кнопку**; (б) проходит **под лучом** | Фигура «сжимается», кнопка загорается |
| 4 | **Щит** | Руки скрещены перед грудью (запястья по разные стороны, между плечами и тазом) | **Блокирует лазер**: луч заканчивается на актёре со щитом | Шестиугольный неоновый щит перед телом, луч обрывается искрами |
| 5 | **Обе руки вверх** (2 с) | Оба запястья выше головы | Подтверждение в меню / «готов» перед раундом | Кольцо прогресса вокруг фигуры |

Курсор в меню — запястье правой руки (или левой, если правая не видна). Кнопка нажимается удержанием 1.2 с (dwell) с кольцом прогресса. Мышь тоже работает.

Минимум 3 разных движения выполнен жестами 2, 3, 4 (+ позиционирование и подтверждение).

## 3. Объекты уровня

| Объект | Параметры | Правило |
|---|---|---|
| `lever` | lane, side (`left`/`right`/`any`), targets: doorId | `held = ∃ актёр в lane с поднятой рукой нужной стороны`. Пока `held` — дверь открыта |
| `plate` (низкая кнопка) | lane, targets | `pressed = ∃ актёр в lane в приседе`. Две фигуры на одной плите = одна |
| `laser` | fromLane, toLane, height (`chest`) , pattern (`always` / `pulse: on 2s, off 2s`) | Луч идёт слева направо (или наоборот). Обрывается на первом актёре со щитом. Актёр в зоне луча, стоящий (не в приседе), — **поражён** |
| `door` | lane, openedBy: [ids], mode `all`/`any` | Открыта, если условие. Закрывает вход в `exit` той же дорожки |
| `exit` | lane, requires doorId?, holdSec 1.0 | Игрок (только живой!) стоит в lane при открытой двери ≥ 1 с → уровень пройден |
| `hazard hit` | — | Поражение = стан 2 с (фигура серая, не считается для плит/рычагов), красная вспышка, подсказка. Не смерть |

Важно: **выход засчитывается только живому игроку**, иначе клон из прошлого раунда «пройдёт» уровень сам.

## 4. Уровни

Длительность раунда T = 20 с (обучение — без таймера). Максимум Эхо на уровне — 3 (4 раунда). Если не прошёл за 4 раунда — уровень перезапускается с подсказкой, что пошло не так.

### L0 — Обучение «Калибровка и жесты» (без Эхо)
1. «Встань так, чтобы было видно колени» → рамка становится зелёной, когда видны точки 0–28 с confidence > 0.5.
2. «Стой прямо 2 с» → калибровка: запоминаем `standHipY`, `torso`.
3. По очереди: «Шагни влево» → «Подними руку» → «Присядь» → «Скрести руки — щит». Каждый жест держать 1 с. На каждом — подсказки режима «ошибка» в мягкой форме.
4. «Подними обе руки — начнём».

### L1 — «Дверь» (1 Эхо, учит идею)
```
lane1: РЫЧАГ(any hand) → открывает ДВЕРЬ lane5
lane5: ДВЕРЬ + ВЫХОД
```
- Раунд 1: игрок идёт в lane 1, поднимает руку. Дверь открывается — но он в lane 1, до выхода не дойти, не отпустив рычаг. Экран между раундами объясняет: «Твоё Эхо теперь будет держать рычаг. Иди к выходу».
- Раунд 2: Эхо №1 держит рычаг, игрок идёт в lane 5.
- Подсказка планирования: если в раунде 1 рука поднята только 6 с из 20 — «Эхо №1 держит рычаг только с 4 по 10 с. Успей в дверь за это время или переиграй раунд».

### L2 — «Два ключа» (2 Эхо)
```
lane1: РЫЧАГ(left hand)  ─┐
lane5: ПЛИТА (присед)     ─┴─ mode all → ДВЕРЬ lane3
lane3: ДВЕРЬ + ВЫХОД
```
- Нужны одновременно рука вверх в lane 1 и присед в lane 5 — один человек физически не может. Раунд 1 — рычаг, раунд 2 — плита, раунд 3 — в центр, к выходу.
- Требование `left hand` для рычага даёт повод для подсказки «Рычаг слева — подними левую руку».
- Игрок стартует в lane 3, где выход, но дверь закрыта → сразу видно цель.

### L3 — «Лазер» (3 Эхо, финал)
```
lane1: РЫЧАГ(any) → ДВЕРЬ lane5
lane2: ЛАЗЕР-излучатель → бьёт вправо через lane3, lane4, lane5 (высота груди, always)
lane4: ПЛИТА(присед) → второе условие ДВЕРИ (mode all)
lane5: ДВЕРЬ + ВЫХОД
```
- Логика решения: Эхо №1 держит рычаг в lane 1. Кто-то должен в lane 4 стоять на плите в приседе — в приседе луч не задевает, отлично, Эхо №2. Но игроку самому нужно пройти lane 3 и встать в lane 5 **стоя** (выход требует стоять? — нет, упростим: выход засчитывается в любой позе, но луч в lane 5 поражает стоящего). Значит нужен щит в lane 3: Эхо №3 стоит со щитом, луч обрывается, lane 4–5 безопасны. Раунд 4 — игрок идёт к выходу.
- Альтернативное решение (умное): игрок в раунде 4 сам проходит lane 3 в приседе и стоит в lane 5 в приседе — если выход не требует стоять, уровень решается за 3 Эхо → больше очков. Оставить эту возможность — это «свобода решения», хорошо для оригинальности.

Если времени мало — L3 сделать с `pulse`-лазером и без плиты (2 Эхо).

## 5. Очки и рекорды

```
score_level = 1000
            + timeLeft * 20            // секунды до конца финального раунда
            + (maxEchoes - usedEchoes) * 500   // меньше клонов = умнее
            - hits * 100               // поражения лазером
            - hintsShown * 10          // штраф за подсказки режима «ошибка» (мягкий)
```
Итог = сумма по уровням. Экран результатов: очки, время, число Эхо на уровне, «самая частая ошибка» (из логов подсказок — это красиво замыкает твист). Таблица рекордов top-10 в `localStorage`, имя вводится... без клавиатуры — выбором из 3 букв курсором-ладонью или просто «Игрок #N» + дата. Проще второе.

## 6. Сценарий целиком (что видит жюри)

1. **Стартовый экран**: логотип ЭХО, «Разреши камеру», кнопка «Играть» (dwell/клик). Пока грузится модель (~5–10 с) — прогресс-бар и подсказка «встань в 2 м от камеры».
2. **L0 Обучение** (≈1 мин).
3. **L1 → L2 → L3**, между раундами — экран «Перемотка» с таймлайном Эхо (что делал в какие секунды) и одной главной подсказкой.
4. **Итоги**: очки, статистика, таблица рекордов, «Сыграть ещё» (снова dwell).

Общее время прохождения — 4–6 минут. Жюри должно успеть за один заход.

## 7. Экран «Перемотка» между раундами

Самый важный UX-элемент для понимания идеи:
```
 ⏪ ПЕРЕМОТКА                      Раунд 2 из 4
 Эхо №1 (циан) будет делать:
  0s ──────■■■■■■■■■■■■■■■■──── 20s   ✋ рычаг lane1: 4–20 с
 Дверь lane5 открыта: 4–20 с
 Подсказка: иди к выходу, пока дверь открыта.
 [Подними обе руки, чтобы начать]
```
Таймлайн строится прогонкой записи через распознаватель + правила уровня в «сухом» режиме (без рендера) — это дёшево, 400 кадров.
