## Риски и что делать

| Риск | Вероятность | План |
|---|---|---|
| Пороги жестов не работают у другого человека / в другой комнате | Высокая | Всё в долях торса + калибровка стойки. `?debug=1`. Тест на 3 людях в день 1. Пороги в одном файле `thresholds.ts` |
| Ног не видно (жюри сидит за ноутбуком) | Высокая | Fallback приседа по плечам (см. 03 §5). Подсказка `legs_hidden`. В README: «встаньте в 1.5–2 м от камеры». На стартовом экране — силуэт-рамка |
| Модель долго грузится с CDN (10 МБ) | Средняя | Прогресс-бар, начать загрузку до нажатия «Играть». Опционально положить `.task` и wasm в `public/` |
| Safari / старые браузеры | Средняя | Проверить в Safari один раз 29.09. Если сломано — баннер «откройте в Chrome» вместо починки |
| Тёмная комната | Средняя | Подсказка `low_conf`; при необходимости canvas `filter: brightness(1.3) contrast(1.2)` перед `detectForVideo` (идея из чужого `useHandTracking`) |
| Низкий fps на слабом ноутбуке | Средняя | Модель уже lite; детект через кадр (15 fps достаточно для поз), рендер всё равно каждый кадр |
| Эхо «рваное» из-за потерь трекинга | Средняя | Последний известный кадр + пауза клока при потере > 1.5 с |
| Жюри не поймёт идею за 30 секунд | Средняя | L1 специально построен так, что игрок сам упирается в «одному не дойти», и экран Перемотки объясняет. Плюс gif в README |
| Уровень слишком сложный, жюри бросает | Средняя | Стан вместо смерти, 4 раунда на уровень, кнопка «Пропустить уровень» через dwell (не стыдно — лучше, чем 0 за работоспособность) |
| Сгорание / не успеть | — | Линия 0 к вечеру 29.09 — священна. Всё после неё — бонус |
