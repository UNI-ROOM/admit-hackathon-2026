# Проверка мобильной версии ECHO 2D

Мобильная 2D кампания реализована: все три уровня проходят пальцами без камеры. Браузерная проверка завершила Easy с записью и воспроизведением Эхо, Hard — с двумя одновременными касаниями. Проверены обучение, пауза, повторный запуск, отмена касания, смена ориентации и диалоги.

## Реализованное поведение

- На сенсорном устройстве главное меню открывает 2D кампанию напрямую. Сложность обозначается числом пальцев.
- Захват выполняется по ближайшему видимому объекту с доступной зоной касания. Pointer capture сохраняет перетаскивание при уходе пальца за границы поля. Отпускание и отмена освобождают соответствующий объект, не меняя идентичность другого пальца.
- На телефоне симуляция работает независимо от камеры. MediaPipe, браузерный Tailwind runtime и Three.js не загружаются в мобильном пути. Стили HUD поставляются вместе с приложением.
- Игровой мир имеет логический размер 600×600 и сохраняет пропорции при повороте. Canvas учитывает плотность пикселей с ограничением коэффициента до двух.
- Верхняя панель показывает уровень, сложность и оставшееся время. Нижняя панель показывает цель и состояние головоломки, кнопки игры, записи и перезапуска. В альбомной ориентации она переносится вправо от поля.
- Мобильные Эхо сохраняют временные отметки кадров. Воспроизведение выбирает кадры по прошедшему времени, сохраняя синхронизацию с движением лазера при изменении частоты кадров.
- Обучение заменяет жесты последовательностью касаний: начать, перенести куб, попробовать перезапуск, открыть меню.
- Открытие диалога освобождает касания. Уход в фон ставит попытку на паузу; возобновление корректирует время. Escape также возобновляет паузу. Следующий уровень после победы выбирается кнопкой.
- Настройки на телефоне содержат звук, музыку, подсказки, доступность уровней, язык и сброс прогресса. Пункты управления камерой предназначены для компьютерного интерфейса.

## Браузерные проверки

Запуск: `cd echo && npm run test:mobile`. Сценарий использует Chromium с `isMobile`, `hasTouch` и настоящими событиями касания через Chrome DevTools Protocol. Состояние движка читается для проверки; объекты переносятся сенсорным вводом, условия победы не подменяются.

| Проверка | Результат |
| --- | --- |
| Easy 1 | Полная запись призмы, воспроизведение Эхо, заряд кристалла и спасение без смерти |
| Easy 2 | Полная запись движущегося щита, воспроизведение Эхо и спасение без смерти |
| Easy 3 | Две последовательные записи рычага и щита, совместное воспроизведение и спасение без смерти |
| Hard 1 | Два пальца удерживают призму и человечка; заряд и спасение без смерти |
| Hard 2 | Рычаг фиксируется; два пальца управляют щитом и человечком до победы |
| Hard 3 | Оба рычага фиксируются; щит и человечек управляются двумя пальцами до победы |
| Запись Hard | Два настоящих касания сохраняются в независимых слотах одного Эхо |
| Обучение | Все четыре шага завершаются касаниями |
| Освобождение | Отпускание одного пальца сохраняет захват другого; отмена освобождает предметы |
| Пауза и перезапуск | Таймер сохраняется после возобновления; Escape закрывает паузу; перезапуск возвращает IDLE |
| Поворот | Попытка сохраняется при переходе из портретного режима в альбомный |
| Диалоги | Профиль, таблица результатов и настройки помещаются в экран 320×568 и прокручиваются без горизонтального переполнения |
| Зависимости | Запросов камеры нет; MediaPipe, Tailwind CDN и Three.js в мобильном сценарии не загружаются |
| Ошибки JavaScript | Не обнаружены |

Проверка ухода в фон в headless браузере использовала моделирование изменения `document.hidden` и отправку настоящего события `visibilitychange`: в этом окружении переключение вкладок не скрывает исходную страницу. Проверен обработчик паузы, а не поведение операционной системы телефона.

## Сборка и регрессии

- `npm run build` — успешно. Vite сообщает предупреждения о размере отдельного 3D чанка и смешанном импорте router; это предупреждения, а не ошибки сборки.
- `npm test` — 132 теста прошли. Дополнительные тесты покрывают перевод координат касания, временные отметки Эхо, сохранение идентичности пальцев при пересечении и освобождение захвата при отмене.
- `npm run test:browser` — существующий сценарий 3D прошёл в Chromium, включая оба режима сложности.
- `git diff --check` — успешно.

## Границы проверки

Серверные ответы в мобильном браузерном сценарии заменены фиксированными тестовыми данными. Проверена игровая механика и обработка результата интерфейсом, а не запись результата в реальную базу данных.

Физические iPhone и Android, Safari на устройстве, системные жесты и реальная производительность телефона не проверялись. Перед публикацией рекомендуется ручное прохождение на одном устройстве каждой платформы, включая поворот, уход в другое приложение и возвращение.
